## 防双响：让「压哪一边」可配置，并把「同一台设备」判得更准

现状（0.6.0）：

- 开关只在「网页响铃 + 宿主提醒」都开着时出现，**默认关**；
- 判定「同一台设备」看页面地址：`localhost` / `127.0.0.1` / `[::1]` 算本机，其余（机器名、局域网 IP）算另一台设备；
- 开启后**压掉浏览器**，只留宿主那一声；宿主没接管（宿主关着、或该事件是「关」）时浏览器照常响。

待办：

1. **「压宿主」目前做不到。** 宿主是在自己的 `record()` 里发声/弹 toast 的，客户端没法撤掉。
   要支持得加一条宿主设置（例如 `dedupeSide`），再让宿主在发声前判断「这台机器上是不是有个
   本机客户端已经响过了」。多客户端（电脑 + 手机同时开着页面）时，还要能区分是哪个客户端提的。
2. **同机判定可以更准。** 页面经机器名（`http://my-pc:3000`）或局域网 IP 打开时，现在按
   「另一台设备」处理（宁可多响一声）。可以给 sysget 加 `hostName`（`os.hostname()`），
   客户端拿 `location.hostname` 与它比对，覆盖这几种地址。
3. 宿主能力探测失败（`capBeep` / `capNotify` 为 false）时目前让浏览器顶上，缺一条专门的回归测试。
